# Barbearia Premium — Agendamento & Gestão

Plataforma demonstrativa para barbearias, com página comercial, agendamento interativo e áreas separadas para proprietário e barbeiro.

**Demo:** https://barbearia-premium-green.vercel.app

## Sobre o projeto

O projeto foi criado para demonstrar uma solução mais completa do que um site institucional tradicional, combinando apresentação comercial, experiência de agendamento e fluxos de gestão em uma única interface.

## Principais recursos

- Página comercial responsiva em português
- Serviços, valores e profissionais apresentados com clareza
- Agendamento demonstrativo sem necessidade de cadastro
- Bloqueio de horários por profissional e duração do serviço
- Atualização da disponibilidade entre abas do navegador
- Painel separado para proprietário
- Painel separado para barbeiro
- Persistência local para demonstrar os fluxos
- Animações e transições de interface

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- date-fns
- Vercel Analytics

## Executar localmente

```bash
npm install
npm run dev
```

Para validar o projeto:

```bash
npm run check
npm run build
```

## Observação

Projeto demonstrativo de portfólio. Para uso comercial real, autenticação, banco de dados compartilhado, política de privacidade, equipe, horários, contatos e demais dados devem ser configurados para o estabelecimento.
